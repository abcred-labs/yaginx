# Security policy

Please do not disclose a suspected vulnerability in a public issue. Send a
minimal reproduction and the affected version to the repository maintainers
through GitHub's private vulnerability reporting flow.

Do not include credentials, private keys, production data, internal hostnames,
or private logs in a report. The project supports the latest tagged release;
security fixes are published through GitHub Releases and announced in the
release notes.

All reports are triaged with the affected component, reproducibility, impact,
and a proposed mitigation. Reporters are credited only with their consent.
