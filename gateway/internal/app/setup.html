TEMPORARY SETUP

Use the one-time token from journalctl -u yaginx. Your DBA must create an empty PostgreSQL database first; this wizard initializes the Yaginx schema and starts the gateway.

The token expires after 15 minutes and is invalidated after setup completes.

The database role must have the DDL privileges required to initialize or migrate the selected database.

Ports have not been checked for the current values.

Use at least 5 characters. Existing databases with accounts keep their current accounts.

Used for ACME registration and certificate renewal notifications. Automatic certificate application and renewal are always enabled.


          
          

        

      

      

        
Enter the database connection fields, then check PostgreSQL.

        
Database setup
Connect to the empty database prepared by your DBA. Yaginx will initialize its schema after review.

        
Operator commands

          
Get setup token
sudo journalctl -u yaginx -n 50 --no-pager

          
Follow setup logs
sudo journalctl -u yaginx -f

          
Refresh expired token
sudo systemctl restart yaginx
sudo journalctl -u yaginx -n 50 --no-pager

          
Service status
sudo systemctl status yaginx --no-pager

        

        
Keep TCP/9090 restricted to the administrator IP. Never paste the setup token or database password into tickets or shell history.
